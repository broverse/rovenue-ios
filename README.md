# Rovenue (Swift Package)

Generated distribution package for the Rovenue Swift SDK
(https://rovenue.io). **Do not send pull requests here** — the source lives in
the Rovenue monorepo under `packages/sdk-swift`, and this repository is
regenerated on every release. MIT licensed (see LICENSE).

Swift Package Manager (the only distribution — there is no CocoaPod):

```swift
.package(url: "https://github.com/broverse/rovenue-ios", from: "0.27.0"),
```

The React Native and Flutter SDKs resolve this package themselves; their apps
add nothing for it.
